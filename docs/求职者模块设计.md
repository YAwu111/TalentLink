# 求职者模块设计

## 1. 范围

当前已实现：

- 求职者个人资料（真实后端）
- 字段级自动保存
- 简历本地 OCR / 规则识别
- 自动生成简历与浏览器打印
- 求职者工作台
- 岗位浏览、岗位详情、投递、我的投递（前端 mock）
- 13 项资料完整度与投递拦截

尚未实现：

- 岗位/投递真实后端 API
- 企业岗位管理
- 管理员审核求职者（业务上不需要）
- 简历附件持久化
- 企业查看简历
- LLM 结构化抽取

## 2. 个人资料字段

`seekers` 新增：

| 字段 | 类型 | 说明 |

| job_intention | VARCHAR(100) | 求职意向 |
| expected_salary_min | INTEGER | 期望月薪下限 |
| expected_salary_max | INTEGER | 期望月薪上限 |

| 字段 | 权重 |

| gender | 4 |

| household | 4 |

- 13 项全部完整才 `is_complete=true`

- 年龄由 `birth_date` 实时计算，不落库
- demo seed 补齐两位求职者的求职意向和期望薪资

## 3. 接口

```http
GET   /api/seeker/profile
PATCH /api/seeker/profile

POST  /api/seeker/profile/recognize
```

### PATCH

- 字段级局部更新
- email/birth_date 支持 null 清空
- 邮箱格式、未来出生日期、薪资区间校验

### OCR 识别

- multipart 文件：PDF/DOCX/PNG/JPG，≤10MB
- 同步写入临时文件，识别后删除
- 复用 PyMuPDF、python-docx、RapidOCR
- 返回 recognition.v1：
  - `fields[].value/confidence/source`
  - `schema_version/provider/model/confidence/warnings/meta`
- 支持识别：姓名、性别、出生日期、电话、邮箱、户籍、学历、专业、学位、学校、技能、求职意向、期望薪资
- 期望薪资支持 `15-20K`、`15000-20000` 等格式

## 4. 前端

顶栏：

```text
工作台 / 个人资料 / 岗位 / 我的投递
```

简历从个人资料/工作台进入 `/seeker/resume`。

### 个人资料

- 13 字段表单，字段级自动保存，800ms 防抖
- 右侧预览 + 完整度环
- 保存状态：等待保存 / 保存中 / 已保存 / 失败
- 离开拦截：保存并离开 / 直接离开 / X 关闭
- 手动填写 / 简历识别模式切换
- OCR 结果默认只勾选空白字段，已有内容需手动勾选覆盖
- 应用结果后合并到表单并触发自动保存
- 简历页支持浏览器打印 / 另存 PDF

### 工作台

- 资料完整度
- 求职者摘要
- 推荐岗位
- 最近投递
- 快捷入口：个人资料、浏览岗位、我的简历

### 岗位与投递（mock）

- 6 个岗位
- 筛选：关键词、城市、行业、薪资区间
- 5 条初始投递，覆盖 submitted/viewed/interview/offered/rejected
- 投递前检查 `can_apply`
- 资料不完整时拦截并提示缺失字段
- 重复投递拦截
- 数据仅内存，刷新恢复初始 mock
