# 求职者模块设计

## 1. 范围

当前已实现：

- 求职者个人资料（真实后端）
- 字段级自动保存
- 可选工作经历
- 简历本地 OCR / 规则识别
- 自动生成简历与浏览器打印
- 求职者工作台
- 真实岗位浏览、岗位详情、投递、我的投递
- 企业查看投递简历并更新已查看/面试中/未通过状态
- 13 项资料完整度与投递拦截

尚未实现：

- 企业发布录用通知（Offer）
- 管理员审核求职者（业务上不需要）
- 简历附件持久化
- LLM 结构化抽取

## 2. 个人资料字段

`seekers` 新增：

| 字段 | 类型 | 说明 |
|---|---|---|
| job_intention | VARCHAR(100) | 求职意向 |
| expected_salary_min | INTEGER | 期望月薪下限 |
| expected_salary_max | INTEGER | 期望月薪上限 |
| work_company | VARCHAR(100) | 工作单位（可选） |
| work_title | VARCHAR(100) | 工作职位（可选） |
| work_start | VARCHAR(20) | 开始时间 |
| work_end | VARCHAR(20) | 结束时间/至今 |
| work_description | TEXT | 工作描述 |

完整度权重：

| 字段 | 权重 |
|---|---:|
| name | 12 |
| gender | 4 |
| birth_date | 8 |
| phone | 12 |
| email | 8 |
| household | 4 |
| education | 8 |
| major | 5 |
| degree | 4 |
| school | 8 |
| skills | 10 |
| job_intention | 8 |
| expected_salary | 9 |

- 13 项全部完整才 `is_complete=true`
- 工作经历为可选项，不参与完整度和投递资格
- 期望薪资要求 min/max 大于 0 且 min ≤ max
- `can_apply` 当前等于完整度
- 年龄由 `birth_date` 实时计算，不落库
- demo seed 补齐两位求职者的求职意向、期望薪资和工作经历

## 3. 接口

```http
GET   /api/seeker/profile
PATCH /api/seeker/profile
POST  /api/seeker/profile/recognize

GET   /api/jobs
GET   /api/jobs/{job_id}

POST  /api/seeker/applications
GET   /api/seeker/applications

GET   /api/employer/jobs
POST  /api/employer/jobs
PATCH /api/employer/jobs/{job_id}
POST  /api/employer/jobs/{job_id}/publish
POST  /api/employer/jobs/{job_id}/close
```

### PATCH

- 字段级局部更新
- email/birth_date 支持 null 清空
- 邮箱格式、未来出生日期、薪资区间校验

### OCR 识别

- multipart 文件：PDF/DOCX/PNG/JPG，≤10MB
- 同步写入临时文件，识别后删除
- 复用 PyMuPDF、python-docx、RapidOCR
- 返回 recognition.v1：
  - `fields[].value/confidence/source`
  - `schema_version/provider/model/confidence/warnings/meta`
- 支持识别：姓名、性别、出生日期、电话、邮箱、户籍、学历、专业、学位、学校、技能、求职意向、期望薪资、工作单位、工作职位、起止时间、工作描述
- 期望薪资支持 `15-20K`、`15000-20000` 等格式
- 工作经历不参与完整度，但识别后会进入表单和简历

### 投递规则

- 求职者 13 项资料完整
- 岗位状态为 published
- 企业资料完整
- 同一求职者与岗位唯一，重复投递返回 409

## 4. 前端

顶栏：

```text
工作台 / 个人资料 / 岗位 / 我的投递
```

简历从个人资料/工作台进入 `/seeker/resume`。

### 个人资料

- 13 个必填字段 + 5 个工作经历字段，字段级自动保存，800ms 防抖
- 工作经历选填，不影响完整度和投递
- 右侧预览 + 完整度环
- 保存状态：等待保存 / 保存中 / 已保存 / 失败
- 离开拦截：保存并离开 / 直接离开 / X 关闭
- 手动填写 / 简历识别模式切换
- OCR 结果默认只勾选空白字段，已有内容需手动勾选覆盖
- 应用结果后合并到表单并触发自动保存
- 简历页支持浏览器打印 / 另存 PDF

### 工作台

- 资料完整度
- 求职者摘要
- 推荐岗位
- 最近投递
- 快捷入口：个人资料、浏览岗位、我的简历

### 岗位与投递（真实后端）

- seed 6 个已发布岗位
- 筛选：关键词、城市、行业、薪资区间（后端过滤）
- 岗位列表返回 `applied` 状态
- 投递前检查 `can_apply`
- 资料不完整时前端提示缺失字段，后端再次校验
- 重复投递由数据库唯一约束和后端校验双重拦截
- 我的投递读取真实 applications，状态覆盖 submitted/viewed/interview/offered/rejected

### 企业岗位管理

- 企业顶栏增加「岗位管理」
- 创建、编辑草稿
- 发布前校验企业资料完整度
- 关闭已发布岗位后从求职者列表下架
- 本轮不提供企业查看投递和状态流转
